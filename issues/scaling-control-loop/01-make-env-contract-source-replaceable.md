# 01 — 讓環境變數對帳檢查的來源可替換

**What to build:** 環境變數三方對帳檢查目前把「機器開機腳本」寫死為對帳的第三方。
那個檔案會在遷移中被刪除，屆時這個檢查會沉默地失去意義 —— 它仍然會通過，但它已經
不再驗證任何東西。這張票不改變檢查現在做的事，只把「設定宣告從哪裡來」變成一個可以
替換的東西，好讓之後指向 task definition 是一行改動而不是一次改寫。

這是 prefactor：先讓改動變容易，再做那個容易的改動。行為在這張票結束時必須完全不變。

**Blocked by:** None — can start immediately.

- [ ] 對帳的第三方來源不再是寫死的路徑
- [ ] 檢查對目前的機器開機腳本仍然得出與改動前完全相同的結果
- [ ] 該檢查既有的自我測試同步更新，且涵蓋「來源可替換」這件事本身
- [ ] 驗證入口不變，仍是既有的單一 harness
